# 由脚本编排渐进学习单元

英文学习单元由固定 OEWN 词典证据、上下文语法角色和版本化通用规则确定，模型只生成中文提示。规则先让多词 OEWN 表达占据最高优先级，再把词典未覆盖且由固定句法模型标为连续 `VERB + prt` 的结构识别为不可拆实义核心，随后用 OEWN 词性兼容、表层命中证据和上下文实义词性处理其余原子；不维护教材词汇白名单。所有实义核心先独立练习，连续的前置修饰名词结构再依据依存中心关系由中心词向左组成自然短语，最后把这些短语视为不可拆的组合组，从右向左合并并吸收原文连接成分。动词小品词属于原子识别，名词短语属于渐进组合，两者分别维护。这使行为可通过教材回归样本统一校正，也避免纯后缀折叠产生 `spaces and lower speed limits` 一类破坏名词短语边界的中间项；代价是分析 schema 需要保存原子间依存中心和句法回退来源，通用判定与组合策略也需要持续维护。非连续表达仍超出当前连续原文片段模型的范围。
